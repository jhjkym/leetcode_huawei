# 43. 字符串相乘

- 算法分类：竖式乘法模拟。
- 数据结构：数位数组 `vector<int>`。
- 对应代码：[043_multiply_strings.cpp](./043_multiply_strings.cpp)。
- 掌握状态：不会，标记为“背诵模板”，待复习背诵。
- 测试说明：17 组固定测例全部通过。

## 题意

给定表示非负整数的字符串 `num1` 和 `num2`，以字符串形式返回它们的乘积。
不能使用大整数库，也不能把整个输入直接转换成整数。可以将单个字符通过减去 `'0'` 转成数字。
两串长度均为 `1` 到 `200`，只含数字，除 `"0"` 本身外没有前导零。

## 背诵模板

**先判零，开 m+n；两串倒着乘，累加已有位；个位放 i+j+1，进位加 i+j；跳过前导零，拼接成字符串。**

核心三行：

```cpp
int sum = (num1[i] - '0') * (num2[j] - '0') + digits[i + j + 1];
digits[i + j + 1] = sum % 10;
digits[i + j] += sum / 10;
```

`sum` 必须加上该位置已有的值；进位使用 `+=`，因为左边一位可能已经有其他乘积的贡献。

## 示例：12 × 34

长度都是 `2`，先创建四位数组 `[0, 0, 0, 0]`，从右向左乘：

| i | j | 本次计算 | 数组结果 |
| --- | --- | --- | --- |
| 1 | 1 | 2 × 4 + 0 = 8 | `[0, 0, 0, 8]` |
| 1 | 0 | 2 × 3 + 0 = 6 | `[0, 0, 6, 8]` |
| 0 | 1 | 1 × 4 + 6 = 10 | `[0, 1, 0, 8]` |
| 0 | 0 | 1 × 3 + 1 = 4 | `[0, 4, 0, 8]` |

跳过开头的 `0`，得到 `"408"`。中间的零必须保留。

## 为什么是 i+j+1 和 i+j

`m` 位数乘 `n` 位数，结果最多有 `m+n` 位。
`num1[i]` 距离个位有 `m-1-i` 位，`num2[j]` 距离个位有 `n-1-j` 位，乘积对应的位置距离个位有 `m+n-2-i-j` 位。
在长度为 `m+n` 的数组中，这个位置的下标就是 `i+j+1`；进位自然加到左边的 `i+j`。

倒序遍历会先处理低位，再处理高位。进位累加后某个位置可能暂时超过 `9`，后续处理到这个位置时会继续取模和进位；循环结束时各位都是合法数字。

## 边界与复杂度

- 任意输入为 `"0"`，直接返回 `"0"`。
- 倒序下标使用 `int`，避免无符号整数减到 `0` 后下溢。
- 只在结果尚为空时跳过零，不能删除中间或末尾的零。
- 时间复杂度 `O(mn)`，辅助空间 `O(m+n)`。
