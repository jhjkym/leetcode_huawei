# 62. 不同路径

## 最优背诵代码

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n, 1);

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] += dp[j - 1];
            }
        }

        return dp[n - 1];
    }
};
```

## 思路

机器人只能向右或向下走，因此到达一个格子的路径数等于：

```text
上方的路径数 + 左方的路径数
```

用一维数组 `dp` 保存当前行：

- 更新前的 `dp[j]` 是上方路径数。
- `dp[j - 1]` 是左方路径数。
- 所以状态转移是 `dp[j] += dp[j - 1]`。

第一行和第一列都只有一种走法，所以把整个 `dp` 初始化为 `1`，并从第 `1` 行、第 `1` 列开始更新。

## 背诵口诀

> 第一行列全是一；当前等于上加左；一维数组原地走。

## 复杂度

- 时间复杂度：`O(m × n)`
- 空间复杂度：`O(n)`
