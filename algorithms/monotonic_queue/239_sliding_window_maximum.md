# 239. 滑动窗口最大值

- 算法分类：滑动窗口、单调队列。
- 数据结构：双端队列 `deque<int>`。
- 对应代码：[239_sliding_window_maximum.cpp](./239_sliding_window_maximum.cpp)。
- 掌握状态：忘记做法，已提供单调队列答案模板，待复习背诵。
- 测试说明：16 组固定测例全部通过。

## 题意

给定整数数组 `nums` 和窗口大小 `k`。窗口从数组最左侧开始，每次向右移动一个位置，返回每个窗口中的最大值，按窗口移动顺序组成数组。

输入保证 `1 <= k <= nums.size()`，数组非空。结果应包含 `nums.size() - k + 1` 个元素。练习目标是 `O(n)` 时间复杂度。

## 示例

```text
输入：nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
输出：[3, 3, 5, 5, 6, 7]
```

| 窗口 | 最大值 |
| --- | --- |
| `[1, 3, -1]` | 3 |
| `[3, -1, -3]` | 3 |
| `[-1, -3, 5]` | 5 |
| `[-3, 5, 3]` | 5 |
| `[5, 3, 6]` | 6 |
| `[3, 6, 7]` | 7 |

## 固定测例覆盖

- 典型混合数组、单元素、`k = 1`、`k = n`。
- 严格递增、严格递减、全部相等。
- 全负数、全零、重复最大值。
- 旧最大值移出窗口、新最大值进入窗口。
- 数值边界、长短不同的窗口。

程序逐例输出输入、预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

**口诀：队头去过期，队尾去小值；下标入队尾，窗满取队头。**

用双端队列保存可能成为窗口最大值的元素下标。下标从队头到队尾递增，对应数值严格递减，因此队头对应当前窗口的最大值。

处理下标 `i` 时：

1. 删除队头过期下标：当前窗口左边界为 `i-k+1`，所以 `dq.front() <= i-k` 时过期。
2. 删除队尾数值小于或等于 `nums[i]` 的下标。新元素不小于它们，而且更晚离开窗口，它们已经不可能比新元素更适合作为后续窗口的最大值。
3. 把当前下标 `i` 加入队尾。
4. 当 `i >= k-1`，窗口已经形成，记录 `nums[dq.front()]`。

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;
    vector<int> result;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        while (!dq.empty() && dq.front() <= i - k) {
            dq.pop_front();
        }
        while (!dq.empty() && nums[dq.back()] <= nums[i]) {
            dq.pop_back();
        }
        dq.push_back(i);
        if (i >= k - 1) result.push_back(nums[dq.front()]);
    }
    return result;
}
```

## 接口和易错点

| 接口 | 作用 |
| --- | --- |
| `dq.empty()` | 判断队列是否为空 |
| `dq.front()` / `dq.back()` | 读取队头 / 队尾元素，不删除 |
| `dq.pop_front()` / `dq.pop_back()` | 删除队头 / 队尾元素，不返回元素 |
| `dq.push_back(i)` | 将下标 `i` 加入队尾 |

- 队列存下标，便于判断是否过期；比较数值时要写 `nums[dq.back()]`。
- 队头删除是因为过期，队尾删除是因为被新元素取代，含义不同。
- 队列不必存下整个窗口，只保留仍可能成为最大值的候选元素。
- 相等时删除旧下标，保留更晚过期的新下标。
- 读取队头、队尾前先检查非空；`&&` 从左向右短路求值。
- 第一个完整窗口在 `i == k-1` 时形成，不能提前输出。

## 复杂度

每个下标入队一次，最多出队一次，因此所有循环合计为 `O(n)` 时间。队列最多保存 `k` 个下标，辅助空间为 `O(k)`；返回数组另占 `O(n-k+1)` 空间。
