## 复习清单

重点盯下面四处，都是反复写错的地方：

1. 第 0 行第 0 列初始化为 `i` 和 `j`，不是全 `0`；
2. `dp` 尺寸 `(m + 1) × (n + 1)`，字符索引用 `i - 1`、`j - 1`；
3. 字符相等时直接继承 `dp[i-1][j-1]`，不加 `1`、不取 `min`；
4. 字符不等时三个方向（左上替换、上删除、左插入）都要进 `min`。

## 题意

给定两个单词 `word1` 和 `word2`，每次操作可以对 `word1` 插入一个字符、删除一个字符或替换一个字符，
求把 `word1` 转换成 `word2` 所需的最少操作数。

约束：`0 <= word1.length, word2.length <= 500`，只含小写字母。

## 动态规划状态

令 `dp[i][j]` 表示把 `word1` 的前 `i` 个字符转成 `word2` 的前 `j` 个字符所需的最少操作数。
注意 `i`、`j` 是**长度**而不是下标，所以字符对应的是 `word1[i - 1]` 和 `word2[j - 1]`。

对最后一个字符分情况：

- 若 `word1[i - 1] == word2[j - 1]`，末字符已经对齐，不花操作：`dp[i][j] = dp[i - 1][j - 1]`；
- 否则在三种操作里取最优，都要 `+1`：
  - 替换：把 `word1[i - 1]` 改成 `word2[j - 1]`，来自 `dp[i - 1][j - 1]`；
  - 删除：删掉 `word1[i - 1]`，来自 `dp[i - 1][j]`；
  - 插入：在 `word1` 末尾插入 `word2[j - 1]`，来自 `dp[i][j - 1]`。

即 `dp[i][j] = 1 + min(dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1])`。

## 边界初始化

第 0 行和第 0 列必须先填，它们不是 0：

- `dp[i][0] = i`：把长度 `i` 的串变成空串，只能删 `i` 次；
- `dp[0][j] = j`：从空串变出长度 `j` 的串，只能插 `j` 次。

漏掉这一步是本题最常见的错误，会让所有结果偏小。`dp[0][0] = 0` 自然成立。

## 三个方向怎么记

`dp` 表里当前格子只看三个邻居，方向和操作一一对应：

- 左上 `dp[i-1][j-1]` → 替换（两串各消耗一个字符）；
- 上方 `dp[i-1][j]` → 删除（只消耗 `word1` 一个字符）；
- 左方 `dp[i][j-1]` → 插入（只消耗 `word2` 一个字符）。

「删除 `word1` 一个字符」和「在 `word2` 上插入一个字符」是等价的，所以不必区分在哪个串上操作。

## 空间压缩

`dp[i][j]` 只依赖上一行和当前行左边，可以压成一维 `dp[j]`。
遍历到 `dp[j]` 时，`dp[j]` 还是旧值（相当于 `dp[i-1][j]`），`dp[j-1]` 已是新值（`dp[i][j-1]`），
左上角 `dp[i-1][j-1]` 会被覆盖，需要额外一个变量在更新前暂存。
面试写二维更稳妥不易错，`500 × 500` 的规模完全够用；压缩版作为进阶优化。

## 边界与易错点

- 第 0 行第 0 列要初始化成 `i` 和 `j`，不能全留 `0`。
- `dp` 尺寸是 `(m + 1) × (n + 1)`，字符索引要用 `i - 1`、`j - 1`，越界和错位都出在这里。
- 字符相等时直接继承 `dp[i-1][j-1]`，不要再 `+1`，也不要跟另外两个方向取 `min`（继承已是最优）。
- 三个方向的 `min` 不能只取两个，漏掉任一种操作都会偏大。
- 这是最小化问题，用 `min` 不是 `max`。
- 两个空串答案为 `0`；一方为空时答案是另一方的长度，靠边界初始化自然覆盖，不需要额外特判。

## 复杂度

设 `m = word1.length()`、`n = word2.length()`。

- 时间复杂度：`O(m · n)`，每个状态计算一次。
- 空间复杂度：二维数组 `O(m · n)`；一维滚动 `O(min(m, n))`。
