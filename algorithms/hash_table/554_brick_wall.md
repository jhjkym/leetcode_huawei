- 算法分类：前缀和、哈希计数。
- 数据结构：二维数组、哈希表。
- 对应代码：[554_brick_wall.cpp](./554_brick_wall.cpp)。

## 题意

一面砖墙由多行砖块组成。`wall[i]` 中的每个整数表示第 `i` 行对应砖块的宽度，各行的总宽度相同，砖块宽度为正整数。

从墙顶到底画一条竖线，返回它最少穿过多少块砖。
如果竖线经过一行中两块砖之间的缝隙，这一行不计入穿过的砖块数。
不能沿墙的左侧或右侧外边缘画线。

## 示例

```text
输入：wall = [[1,2,2,1], [3,1,2], [1,3,2], [2,4], [3,1,2], [1,3,1,1]]
输出：2
解释：在距离左边缘 4 的位置画线，只穿过第 1、4 行的砖块。

输入：wall = [[1], [1], [1]]
输出：3
解释：每行只有一块砖，没有内部砖缝。

输入：wall = [[2,3]]
输出：0
解释：沿唯一一行的内部砖缝画线，不穿过任何砖块。
```

## 固定测例覆盖

- 典型多行砖墙、单行单砖、单行多砖。
- 每行都没有内部砖缝、所有行有共同砖缝。
- 各行砖缝错开、部分对齐、同一行多个砖缝。
- 单砖行与多砖行混合、靠近左右两侧的最优位置。
- 大宽度砖块。

程序逐例输出输入、预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

对每一行累加砖块宽度，得到内部砖缝距离左边缘的位置，用哈希表统计每个位置出现的次数。
同一位置出现的次数，就是在这里画线时可以避开的砖块数，因此答案为：

```text
最少穿砖数 = 墙的行数 - 最多对齐的内部砖缝数
```

代码中的 `map[sum]++` 统计位置 `sum` 上有多少行存在砖缝，`result` 保存最大的出现次数，最终返回 `m - result`。
砖块宽度为正数，所以同一行的内部砖缝位置不会重复。

## 易错点与接口

- 内层循环只处理到倒数第二块砖，排除右侧外边缘；也没有统计初始位置 `0`，因此左侧外边缘同样被排除。
- 每一行都要重新将 `sum` 设为 `0`。
- `unordered_map<long long, int>` 用砖缝位置作键、出现次数作值。`map[sum]` 在键不存在时会插入初始值 `0`，随后自增。
- `long long sum` 用于保存累计宽度，避免较大宽度累加时发生 `int` 溢出。
- 如果每行都只有一块砖，哈希表为空，`result` 保持 `0`，返回总行数。
- `for (auto nums : wall)` 会复制每行数组；可以写成 `for (const auto& nums : wall)` 避免复制，不影响答案。
- 题目保证每行非空，因此当前的 `nums.size()-1` 有效；也可以使用 `size_t i = 0; i + 1 < nums.size(); ++i` 避免无符号减法和有符号比较。

## 复杂度

设砖块总数为 `B`，不同内部砖缝位置数为 `U`，单行最多砖块数为 `W`。
哈希操作平均为常数时间，总时间平均为 `O(B)`。当前按值遍历每行，辅助空间为 `O(U + W)`；改为常量引用遍历后为 `O(U + 1)`。两者均可统一给出 `O(B)` 的辅助空间上界。
