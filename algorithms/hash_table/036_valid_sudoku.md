# 36. 有效的数独

- 算法分类：直接寻址计数（布尔数组判重）。
- 数据结构：三个二维布尔数组。
- 对应代码：[036_valid_sudoku.cpp](./036_valid_sudoku.cpp)。
- 掌握状态：**不会，已提供答案模板，待复习背诵。**

## 题意

检查一个 `9×9` 的数独棋盘，已有数字必须满足：每行不重复、每列不重复、每个 `3×3` 九宫格内不重复。输入只含 `'1'` 到 `'9'` 和表示空格的 `'.'`。

只检查已有数字是否合法，不需要填空，也不要求棋盘一定有解。

## 背诵模板

**空格跳过，数字减一；行列宫查重，没重就标记。**

```cpp
bool isValidSudoku(vector<vector<char>>& board) {
    bool rows[9][9] = {};
    bool cols[9][9] = {};
    bool boxes[9][9] = {};
    for (int r = 0; r < 9; ++r) {
        for (int c = 0; c < 9; ++c) {
            if (board[r][c] == '.') continue;
            int d = board[r][c] - '1';
            int b = (r / 3) * 3 + c / 3;
            if (rows[r][d] || cols[c][d] || boxes[b][d]) return false;
            rows[r][d] = cols[c][d] = boxes[b][d] = true;
        }
    }
    return true;
}
```

## 三个数组的含义

- `rows[r][d]`：第 `r` 行是否出现过数字 `d+1`。
- `cols[c][d]`：第 `c` 列是否出现过数字 `d+1`。
- `boxes[b][d]`：第 `b` 个九宫格是否出现过数字 `d+1`。

`= {}` 将所有元素初始化为 `false`，局部数组在每次调用时重新初始化。
三个条件之间使用 `||`，任何一项已经为真，就说明重复。没有重复才同时标记三项为真。

## 为什么减去 '1'

数字字符 `'1'` 到 `'9'` 要映射为数组下标 `0` 到 `8`，所以写 `board[r][c] - '1'`。例如 `'5' - '1' == 4`。
若减去 `'0'`，数字 `9` 会变成下标 `9`，超出第二维的范围。

## 九宫格编号

```text
0 1 2
3 4 5
6 7 8
```

`r / 3` 表示位于第几排宫，`c / 3` 表示位于第几列宫，整数除法舍去小数部分。
每排三个宫，所以 `b = (r / 3) * 3 + c / 3`。

例如 `(r,c) = (5,7)`：`r/3=1`，`c/3=2`，宫编号为 `1*3+2=5`。
注意不能写成 `r/3+c/3`，否则不同宫会得到相同编号。

## 复杂度与测试

固定 `9×9` 棋盘，最多检查 81 个格子，使用 243 个布尔标记，时间和辅助空间均为 `O(1)`。

14 组固定测例覆盖有效棋盘、完整棋盘、全空、单数字、行列宫分别冲突、宫边界、数字端点、无重复但无解和重复调用。
