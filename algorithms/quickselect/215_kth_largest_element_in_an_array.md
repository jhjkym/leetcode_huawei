# 215. 数组中的第K个最大元素

- 算法分类：堆维护前 k 大元素。
- 数据结构：小根堆 `priority_queue<int, vector<int>, greater<int>>`。
- 对应代码：[215_kth_largest_element_in_an_array.cpp](./215_kth_largest_element_in_an_array.cpp)。
- 练习状态：已完成小根堆解法，逻辑正确；平均 O(n) 的快速选择解法待练习。
- 测试说明：16 组固定测例全部通过。

## 题意

给定整数数组 `nums` 和整数 `k`，返回数组中第 `k` 个最大的元素。
这里按降序排列后的名次计算，重复元素也占据名次，不能先去重。
输入保证 `1 <= k <= nums.size()`，数组非空。练习目标是设计平均时间复杂度为 `O(n)` 的算法。

## 示例

```text
输入：nums = [3, 2, 1, 5, 6, 4], k = 2
输出：5
解释：降序排列为 [6, 5, 4, 3, 2, 1]，第 2 个元素是 5。

输入：nums = [3, 2, 3, 1, 2, 4, 5, 5, 6], k = 4
输出：4
解释：降序排列为 [6, 5, 5, 4, 3, 3, 2, 2, 1]。

输入：nums = [9, 9, 8, 7], k = 2
输出：9
解释：重复的 9 也参与排名。
```

## 固定测例覆盖

- 典型乱序数组、单元素、双元素。
- 全部相同、重复最大值、重复元素跨越目标名次。
- 升序、降序、全负数、正负数与零混合。
- `k = 1`、`k = n`、数值边界。

测试时会复制输入数组，允许实现原地修改数组。程序逐例输出预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

维护一个最多包含 `k` 个元素的小根堆，始终保存当前见过的最大的 `k` 个元素（不足 `k` 个时全部保存）。

1. 堆未满时，直接加入当前数字。
2. 堆满后，如果当前数字大于堆顶，就弹出堆顶并加入当前数字。
3. 否则跳过，因为当前数字无法提高前 `k` 大元素的排名。
4. 遍历结束后，堆顶是最大的 `k` 个元素中最小的那个，也就是第 `k` 大元素。

例如 `[3, 2, 1, 5, 6, 4]`，`k = 2`：先保留 `2、3`，跳过 `1`；遇到 `5` 淘汰 `2`，遇到 `6` 淘汰 `3`，最后跳过 `4`。堆中剩下 `5、6`，堆顶为 `5`。

## 接口与易错点

- `greater<int>` 让堆顶为最小值；默认的 `priority_queue<int>` 则是大根堆。
- `pq.size()` 返回元素数量，`pq.push(num)` 插入元素。
- `pq.top()` 读取堆顶，`pq.pop()` 删除堆顶且不返回该元素。
- 重复元素可以入堆，不会自动去重，因此符合本题的排名要求。
- 堆满时，等于堆顶的数字可以跳过，替换后堆内数值不会改变。
- 输入保证 `1 <= k <= nums.size()`，所以最终堆非空，读取堆顶安全。

## 复杂度与后续练习

时间复杂度通常写为 `O(n log k)`；为覆盖 `k = 1` 时仍需遍历数组，统一写成 `O(n log(k + 1))` 更严谨。辅助空间为 `O(k)`。

当前实现得到的答案正确，但没有达到平均 `O(n)` 的练习目标。后续可练习随机化快速选择：利用分区只继续处理目标下标所在的一侧，平均时间 `O(n)`，最坏时间 `O(n²)`。
