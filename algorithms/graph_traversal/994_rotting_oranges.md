# 994. 腐烂的橘子

- 算法分类：多源 BFS（广度优先搜索）。
- 数据结构：二维网格、队列 `queue<pair<int, int>>`。
- 对应代码：[994_rotting_oranges.cpp](./994_rotting_oranges.cpp)。
- 掌握状态：**不会，已提供答案模板，待复习背诵。**

## 题意

网格中 `0` 表示空格，`1` 表示新鲜橘子，`2` 表示腐烂橘子。每分钟，腐烂橘子会让上下左右相邻的新鲜橘子腐烂，不能斜着传播，也不能跨过空格。
返回全部橘子腐烂的最少分钟数；无法全部腐烂则返回 `-1`，一开始没有新鲜橘子则返回 `0`。输入保证网格非空且为矩形。

## 背诵口诀

**烂橘先入队，鲜橘数清楚；一层一分钟，入队就标烂；剩鲜返负一。**

1. 扫描网格，把所有初始腐烂橘子的坐标加入队列，同时统计新鲜橘子数量。
2. 队列非空且仍有新鲜橘子时，处理当前一层。
3. 保存本层队列长度，只弹出这么多个坐标，检查各自上下左右的邻居。
4. 遇到新鲜橘子，立即标记腐烂、减少新鲜数量并入队。
5. 每处理完一层，分钟数加一。最后检查是否还剩新鲜橘子。

## 为什么是多源 BFS

所有初始腐烂橘子同时传播，所以必须一起入队，它们都是第 0 分钟的起点。
BFS 按层扩散，第 1 层是第 1 分钟变烂的橘子，第 2 层是第 2 分钟变烂的橘子。每个橘子首次被访问时，就是它从最近腐烂源受到感染的最早时刻。

例如一行 `[2, 1, 1, 1, 2]`：

```text
第 0 分钟：[2, 1, 1, 1, 2]
第 1 分钟：[2, 2, 1, 2, 2]
第 2 分钟：[2, 2, 2, 2, 2]
```

两端同时传播，答案是 `2`。

## 关键代码与接口

```cpp
while (!q.empty() && fresh > 0) {
    int size = static_cast<int>(q.size());
    for (int i = 0; i < size; ++i) {
        // 弹出一个坐标，检查四个方向，把新腐烂的橘子入队。

return fresh == 0 ? minutes : -1;
```

| 用法 | 作用 |
| --- | --- |
| `queue<pair<int, int>>` | 队列中每项保存行、列两个整数 |
| `q.push({x, y})` | 将坐标加入队尾 |
| `q.front()` | 读取队头，不删除 |
| `q.pop()` | 删除队头，不返回元素 |
| `q.empty()` / `q.size()` | 判断是否为空 / 读取当前元素数量 |
| `auto [x, y] = q.front()` | C++17 结构化绑定，将坐标复制到两个变量中 |
| `dirs[4][2]` | 保存上下左右的行列偏移量 |

## 易错点

- 必须先保存 `size = q.size()`，不能让新入队的橘子在同一分钟继续传播。
- 入队时就标记为 `2`，避免多个腐烂邻居重复处理同一个新鲜橘子。
- 先检查坐标范围，再访问网格。
- 外层条件加 `fresh > 0`，避免全部变烂后多算一分钟；也保证一开始没有新鲜橘子时返回 `0`。
- 队列空了仍有新鲜橘子，说明它们无法被感染，返回 `-1`。
- 算法会原地修改网格，测试时复制输入。

## 复杂度与测试

设网格有 `m` 行、`n` 列，每个橘子最多入队一次，每次检查四个方向，时间复杂度为 `O(mn)`；队列最坏占用 `O(mn)` 辅助空间。

16 组固定测例覆盖典型传播、无法全部腐烂、空格、单个橘子、全新鲜、全腐烂、单行单列、多源同时传播、斜向不相邻和重复邻接。
