# 88. 合并两个有序数组

- 算法分类：双指针。
- 数据结构：数组 `vector<int>`。
- 对应代码：[088_merge_sorted_array.cpp](./088_merge_sorted_array.cpp)。
- 练习状态：已完成逆向双指针解法，精简为单循环；原实现已达到最优的最坏时间和辅助空间复杂度。
- 测试说明：16 组固定测例全部通过。

## 题意

给定两个按非递减顺序排列的整数数组，以及它们的有效元素数量 `m` 和 `n`，将它们合并成一个有序数组，存入 `nums1`。

- `nums1` 的长度为 `m+n`，前 `m` 个元素是有效数据，末尾的 `n` 个零用于预留空间。
- `nums2` 长度为 `n`，所有元素都是有效数据。
- 有效元素本身也可以是零；是否有效由 `m`、`n` 决定，不能按数值是否为零判断。
- 函数返回 `void`，需要直接修改 `nums1`；重复元素需要保留。
- `m` 或 `n` 可以为零，输入保证 `m+n >= 1`。

## 示例

```text
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
修改后的 nums1：[1,2,2,3,5,6]
解释：nums1 中的有效数据为 [1,2,3]，末尾三个零是预留位置。

输入：nums1 = [1], m = 1, nums2 = [], n = 0
修改后的 nums1：[1]

输入：nums1 = [0], m = 0, nums2 = [1], n = 1
修改后的 nums1：[1]
```

## 固定测例覆盖

- 典型交错合并、有效数组为空。
- 一个数组的元素全部位于另一个数组之前或之后。
- 重复元素、全部相同、有效数据中的零。
- 负数、正负数混合、长度不同和数值边界。

测试会复制两个输入数组，调用 `merge` 后检查 `nums1` 是否与预期结果完全相同，不对实际结果额外排序。

## 解题记录

从两个有效序列的末尾比较，每次把较大的数写到 `nums1` 最后一个待填位置。

| 变量 | 含义 | 初始值 |
| --- | --- | --- |
| `i` | nums1 中最后一个尚未合并的有效元素下标 | `m-1` |
| `j` | nums2 中最后一个尚未合并的元素下标 | `n-1` |
| `tail` | nums1 中下一个写入位置 | `m+n-1` |

```cpp
void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
    int i = m - 1, j = n - 1, tail = m + n - 1;
    while (j >= 0) {
        if (i >= 0 && nums1[i] > nums2[j]) {
            nums1[tail--] = nums1[i--];
        } else {
            nums1[tail--] = nums2[j--];
        }
    }
}
```

**口诀：两尾比大小，大的往后放；二号没放完，循环不能停。**

## 为什么从后向前

`nums1` 尾部已有预留空间。从后面填最大值，可以避免覆盖前面尚未读取的有效元素。
循环过程中始终有 `tail = i + j + 1`；当 `j >= 0` 时，`tail > i`，写入位置在 nums1 未处理部分的后面。

## 为什么只需一个循环

- `j < 0`：nums2 已全部放好，此时 `tail == i`，nums1 剩余元素就在正确位置，无需再复制。
- `i < 0`：nums1 已处理完，条件中的 `i >= 0` 为假，直接复制 nums2 的剩余元素。
- 不需要单独判断 `tail >= 0`：循环里 `j >= 0`、`i >= -1`，所以 `tail = i+j+1 >= 0`。
- `&&` 短路求值保证 `i < 0` 时不访问 `nums1[i]`。

原实现的三个循环也正确，精简主要减少了冗余检查和 nums1 剩余元素的自我复制，复杂度不变。

## 边界与复杂度

- `m = 0`：把 nums2 的元素依次填入 nums1。
- `n = 0`：循环不执行，nums1 保持原样。
- 两个尾部数字相等时先取 nums2，另一个仍会保留，不丢失重复元素。
- `tail--`、`i--`、`j--` 是先使用原下标，再减一。
- 最坏时间复杂度为 `O(m+n)`，辅助空间为 `O(1)`，输入预留空间不计为额外空间。
