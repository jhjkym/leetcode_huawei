# 11. 盛最多水的容器

- 算法分类：双指针（相向双指针）。
- 数据结构：数组。
- 对应代码：[011_container_with_most_water.cpp](./011_container_with_most_water.cpp)。
- 练习状态：`maxArea` 已完成，12 组固定测例全部通过。

## 题意

给定非负整数数组 `height`，下标 `i` 处有一条高度为 `height[i]` 的竖线。
选择两条竖线，与横轴共同构成容器，返回最多可以容纳的水量；容器不能倾斜。
两条线之间的其他竖线不影响这一对边界构成的容量。

如果选择下标 `left` 和 `right`，其中 `left < right`，容量为：

`min(height[left], height[right]) * (right - left)`

高度受较短的一侧限制，宽度是两个下标的距离。
例如 `[1,8,6,2,5,4,8,3,7]` 选择下标 `1` 和 `8`，面积为 `7 * 7 = 49`。

## 双指针思路

让 `left` 指向数组开头，`right` 指向数组末尾，最大面积初始为 `0`。
当 `left < right` 时，重复以下步骤：

1. 根据当前两条边界计算面积，并更新最大面积。
2. 比较两端高度，将较短一侧的指针向内移动一步。
3. 如果两端高度相等，可以移动任意一侧。

先计算面积再移动指针，才能把当前边界组合纳入比较。
指针相遇后已经没有两条不同的竖线，返回记录的最大面积即可。

当前实现每轮先用 `min(height[left], height[right]) * (right - left)` 计算面积，更新 `maxWater` 后再移动指针。
左侧较短时执行 `left++`，其余情况执行 `right--`；两侧等高时选择移动右指针，符合上述规则。
每轮恰好移动一个指针，直到两端相遇，循环能够正常结束。

## 为什么移动较短的一侧

假设当前 `height[left] <= height[right]`，已经计算过当前面积。
如果固定 `left`，把右端点换成区间内部任意位置 `k`，则：

- 新宽度 `k - left` 小于原宽度 `right - left`。
- 新高度 `min(height[left], height[k])` 不会超过 `height[left]`。
- 因此新面积不可能超过刚刚计算的当前面积。

这说明在当前剩余区间内，所有以 `left` 为左端点的组合都不可能改善答案，可以排除这个端点。
将左指针右移不会漏掉更优解；右侧更短时，按同样的理由左移右指针。
两侧等高时，两边都满足上述排除条件，因此任选一侧移动即可。
每轮先保留当前面积，再排除一个已经证明无需继续考察的端点，最终得到全局最大值。

## 边界与易错点

- 宽度是 `right - left`，不是 `right - left + 1`。
- 高度必须取两端的最小值，不能取最大值或相加。
- 不能排序：原下标决定宽度，排序会改变题意。
- 两根柱子时，唯一组合也必须计算；循环条件为 `left < right`。
- 零高度合法，全为零时最大面积就是 `0`。
- 移动较高的一侧不能提高固定短边的上限，应根据较短一侧决定收缩方向。
- 不要只找最高两根柱子或相邻的局部峰值，宽度也决定容量。
- 面积不一定随着指针移动而增加，要始终保留此前找到的最大值。

## 复杂度

- 时间复杂度：`O(n)`，每一步至少移动一个指针，两端总共移动至多 `n - 1` 次。
- 算法辅助空间：`O(1)`，仅需两个下标、当前面积及最大面积等变量。
- 入口参数 `vector<int>& height` 通过引用访问原数组，不会复制数组。
- `main` 为运行测例而复制输入属于测试框架开销，不计入核心算法的辅助空间。

## 固定测例

`main` 内置以下 12 组输入，显示预期值、实际值、PASS/FAIL 和通过总数。
预期值已独立枚举所有成对下标，按题意计算面积并取最大值核对。
当前实现已使用 `g++ -std=c++17 -O2` 编译并运行，12 组测例全部通过。

| 输入 | 预期最大面积 | 覆盖点 |
| --- | --- | --- |
| `[1,8,6,2,5,4,8,3,7]` | `49` | 典型输入，较宽组合取得最优值 |
| `[1,1]` | `1` | 只有两根柱子 |
| `[0,0]` | `0` | 两根柱子均为零 |
| `[0,0,0,0]` | `0` | 多根柱子全部为零 |
| `[4,4,4,4]` | `12` | 全部等高，最宽组合最优 |
| `[1,2,3,4,5]` | `6` | 高度严格递增 |
| `[5,4,3,2,1]` | `6` | 高度严格递减 |
| `[1,2,1]` | `2` | 中间更高，首尾等高 |
| `[4,3,2,1,4]` | `16` | 首尾即为最优边界 |
| `[2,3,10,5,7,8,9]` | `36` | 最优左端点位于内部 |
| `[0,5,0,0,5,0]` | `15` | 首尾为零，内部有最优组合 |
| `[1,100,100,1]` | `100` | 两根相邻高柱优于首尾组合 |
