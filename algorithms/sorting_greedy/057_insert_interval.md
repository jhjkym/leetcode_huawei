# 57. 插入区间

- 算法分类：有序区间扫描、合并。
- 数据结构：区间数组。
- 对应代码：[057_insert_interval.cpp](./057_insert_interval.cpp)。
- 掌握状态：**不会，已提供答案模板，待复习背诵。**
- 测试说明：16 组固定测例全部通过。

## 题意

给定按起点升序排列且互不重叠的区间数组 `intervals`，以及一个新区间 `newInterval`。
插入新区间并合并所有重叠部分，返回仍按起点升序排列且互不重叠的区间数组。不要求原地修改。

区间是闭区间，共用端点也算重叠。例如 `[1,3]` 与 `[3,5]` 应合并为 `[1,5]`。
原区间数组可以为空；每个区间满足起点不大于终点。

## 示例

```text
输入：intervals = [[1,3],[6,9]], newInterval = [2,5]
输出：[[1,5],[6,9]]

输入：intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
输出：[[1,2],[3,10],[12,16]]

输入：intervals = [], newInterval = [5,7]
输出：[[5,7]]
```

## 固定测例覆盖

- 典型单区间和多区间合并。
- 空数组、插在开头、结尾和中间空隙。
- 新区间被包含、新区间覆盖全部、完全相同。
- 左右端点重合、新区间连接多个区间。
- 单点区间、零端点和数值边界。

测试会复制两个输入参数，允许实现修改它们。结果直接按顺序比较，检查是否有序。
程序逐例输出预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

**口诀：左边直接放，中间合成段，右边接着放。**

用 `left`、`right` 保存新区间的边界，用同一个下标 `i` 分三段扫描：

1. `intervals[i][1] < left`：旧区间完全在左边，直接放入结果。
2. `intervals[i][0] <= right`：旧区间与当前合并区间重叠，更新 `left = min(left, 旧起点)`、`right = max(right, 旧终点)`。
3. 合并结束后加入一次 `[left,right]`，再追加右侧所有剩余区间。

原区间已经有序且互不重叠，重叠部分必然连续出现，因此无需重新排序。

## 示例

```text
原区间：[[1,2],[3,5],[6,7],[8,10],[12,16]]
新区间：[4,8]

左边：[1,2] 直接加入。
中间：[4,8] 合并 [3,5] → [3,8]
      [3,8] 合并 [6,7] → [3,8]
      [3,8] 合并 [8,10] → [3,10]
右边：[12,16] 直接加入。

结果：[[1,2],[3,10],[12,16]]
```

## 易错点

- 左边条件用 `<`，合并条件用 `<=`：端点相等也需要合并。
- 第二段只检查起点，是因为第一段已排除了完全在左侧的区间。
- 每次合并都更新右边界，后续判断使用更新后的 `right`。
- 合并后的区间在第二段循环结束后加入一次，不能每次合并都加入。
- 三段扫描共用 `i`，不重置下标；每个区间只处理一次。
- 即使原数组为空，也会加入新区间，正确返回单个区间。
- 当前实现使用局部边界变量，不修改两个输入参数。

## 复杂度

时间复杂度 `O(n)`；除返回数组外辅助空间为 `O(1)`，返回数组最多包含 `n+1` 个区间，占 `O(n+1)` 空间。
