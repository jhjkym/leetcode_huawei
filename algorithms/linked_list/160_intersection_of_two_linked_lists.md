# 160. 相交链表

- 算法分类：双指针、链表。
- 数据结构：单链表节点。
- 对应代码：[160_intersection_of_two_linked_lists.cpp](./160_intersection_of_two_linked_lists.cpp)。
- 练习状态：已完成双指针实现，检查通过。
- 掌握状态：双指针切换头节点的细节待复习。

## 题意

给定两个单链表的头节点，找出它们相交的起始节点。相交表示两个指针指向同一个节点，节点的数值相同不代表相交；如果不相交，返回 `nullptr`。

## 参考方向

可以使用双指针：让两个指针分别走过 A、B 两条链表，切换到另一条链表的头部，消除两条链表长度不同造成的差异。

例如 A 的独有部分长度为 `x`，B 的独有部分长度为 `y`，公共部分长度为 `z`：

```text
a 总路程：x + z + y
b 总路程：y + z + x
```

## 易错点

- 比较节点指针 `a != b`，不能比较 `a->val != b->val`。
- 判断空指针后才能访问 `next`；三元表达式的两条分支分别处理“走到末尾”和“继续走”。
- 相交节点之后的尾部完全相同，不需要额外判断尾部。
- 两个头节点都为空时，循环不执行，直接返回 `nullptr`。
- 测试中可以让两个链表共享同一个 `ListNode*`，不能只创建数值相同的节点。

## 复杂度

每个指针最多走过两条链表各一次，时间复杂度 `O(m+n)`；只使用两个指针，辅助空间 `O(1)`。
