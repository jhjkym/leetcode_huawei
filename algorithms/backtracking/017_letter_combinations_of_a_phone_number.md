# 17. 电话号码的字母组合

- 算法分类：回溯。
- 数据结构：数字到字母的映射、路径字符串、结果数组。
- 对应代码：[017_letter_combinations_of_a_phone_number.cpp](./017_letter_combinations_of_a_phone_number.cpp)。
- 练习状态：已完成回溯实现，检查通过。
- 测试说明：16 组固定测例全部通过，包括同一对象多次调用。

## 题意

给定由数字 `2` 到 `9` 组成的字符串，为每个数字选择它在电话按键上对应的一个字母，按原数字顺序组成字符串，返回所有可能的组合。结果顺序不限。

| 数字 | 字母 |
| --- | --- |
| 2 | abc |
| 3 | def |
| 4 | ghi |
| 5 | jkl |
| 6 | mno |
| 7 | pqrs |
| 8 | tuv |
| 9 | wxyz |

## 示例

```text
输入：digits = "23"
输出：["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]

输入：digits = "2"
输出：["a", "b", "c"]
```

模板同时保留空输入的边界练习：`digits = ""` 时返回空数组 `[]`，不是包含空字符串的 `[""]`。

## 固定测例覆盖

- 每个数字的字母映射，特别是 `7` 和 `9` 都有四个字母。
- 两位、三位数字，重复数字和不同数字顺序。
- 空输入。
- 复用同一个 `Solution` 对象多次调用，检查结果和路径是否残留。

测试会对预期结果和实际结果排序后比较，允许任意返回顺序，同时检测重复或遗漏的组合。

## 解题记录

`index` 表示当前处理第几个数字，`path` 保存已经选择的字母，`ans` 收集完整组合。
每层通过 `digits[index] - '0'` 找到对应按键，遍历该按键的字母：加入路径，递归处理下一个数字，然后删除刚加入的字母，尝试下一种选择。
当 `index == digits.size()` 时，所有数字都已处理，将路径保存到结果并返回。

**口诀：一层一个数字，遍历对应字母；加入、递归、撤销，到底保存结果。**

## 易错点与参数传递

- `key[0]`、`key[1]` 用空字符串占位，数字可以直接作为映射下标。
- `ans` 按引用传递，各层递归把答案写入同一个结果数组。
- 当前 `path` 按值传递，子调用不会修改父调用的路径，但父调用执行了 `path += c`，所以本层循环下一次迭代前仍要 `pop_back()`，否则字母会累积。
- `digits` 按值传递，每次递归都会复制整个输入；可改为 `const string& digits` 避免复制。
- `path` 也可以改为 `string& path`，继续保留加入和撤销操作，减少路径复制。
- 空输入提前返回空数组，避免递归终止时加入一个空字符串。
- `ans` 和入口的 `path` 都是局部变量，多次调用不会残留结果。

## 复杂度

设数字个数为 `n`，组合数为 `C`（每位对应 3 或 4 个字母，最多 `4^n`）。生成并保存全部字符串需要 `O(nC)` 时间，最坏为 `O(n·4^n)`。
当前 `path` 和 `digits` 按值递归传递，递归链上的字符串副本合计占 `O(n²)` 辅助空间；结果另占 `O(nC)` 空间。
若路径改为引用、输入改为常量引用，辅助空间可降为 `O(n)`，包含递归栈和共享路径。
