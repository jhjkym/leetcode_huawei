# 264. 丑数 II

- 算法分类：动态规划、三指针。
- 数据结构：状态数组 `vector<long long>`。
- 对应代码：[264_ugly_number_ii.cpp](./264_ugly_number_ii.cpp)。
- 掌握状态：**不会，已提供答案模板，待复习背诵。**

## 题意

丑数是只包含质因数 `2`、`3`、`5` 的正整数。规定 `1` 是第一个丑数，返回从小到大排列的第 `n` 个丑数。

## 背诵答案

```cpp
int nthUglyNumber(int n) {
    vector<long long> dp(n + 1);
    dp[1] = 1;
    int p2 = 1, p3 = 1, p5 = 1;

    for (int i = 2; i <= n; ++i) {
        dp[i] = min({dp[p2] * 2, dp[p3] * 3, dp[p5] * 5});
        if (dp[i] == dp[p2] * 2) ++p2;
        if (dp[i] == dp[p3] * 3) ++p3;
        if (dp[i] == dp[p5] * 5) ++p5;
    }
    return dp[n];
}
```

**口诀：dp 从 1 开始，三个指针乘 2、3、5；取最小，重复指针都前进。**

`dp[i]` 表示第 `i` 个丑数。下一个丑数一定来自某个已经生成的丑数乘以 `2`、`3` 或 `5`，因此取三个候选值的最小值。

如果最小值同时等于多个候选值，必须让对应的多个指针都前进，避免生成重复数字。例如 `6` 既可以由 `2×3` 得到，也可以由 `3×2` 得到。

`p2`、`p3`、`p5` 分别指向下一个需要乘以 `2`、`3`、`5` 的丑数。每轮先取三个候选值的最小值，再把所有等于该最小值的指针向后移动。例如生成 `6` 时，乘 `2` 和乘 `3` 的候选可能同时是 `6`，两个指针都必须前进。

## 易错点

- `dp[1] = 1`，下标从 `1` 开始，三个指针也从 `1` 开始。
- 比较相等时使用三个独立的 `if`，不能写成 `else if`，否则重复候选只移动一个指针。
- `1` 不是由 `2、3、5` 乘出来的，需要作为初始丑数。
- 使用 `long long` 计算乘积，避免中间乘法溢出；题目返回值范围内最终结果可转为 `int`。
- 题目保证 `1 <= n <= 1690`。

## 复杂度

生成前 `n` 个丑数，每轮只做常数次计算，时间复杂度 `O(n)`，状态数组空间 `O(n)`。
