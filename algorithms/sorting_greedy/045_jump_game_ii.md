## 题意

给定非负整数数组 `nums`，从下标 `0` 出发，`nums[i]` 表示在位置 `i` 最多可以向右跳多少步。可以选择小于这个上限的跳跃距离。

返回到达最后一个下标所需的最少跳跃次数。输入保证数组非空且一定能到达末尾；只有一个元素时，答案为 `0`。

## 示例

```text
输入：nums = [2, 3, 1, 1, 4]
输出：2
解释：下标 0 → 1 → 4，共跳两次。

输入：nums = [2, 3, 0, 1, 4]
输出：2

输入：nums = [0]
输出：0
```

## 固定测例覆盖

- 典型输入、路径中包含零。
- 单元素、双元素、每次只能跳一步。
- 一次即可到达末尾、跳跃上限超过剩余距离。
- 需要跨过零、不同跳跃次数、末尾无需继续跳。

所有测例均保证末尾可达。程序逐例输出输入、预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

按跳跃次数扩展可达范围，不必确定每一步具体落在哪个位置。

- `count`：已经计入的跳跃次数。
- `end`：当前跳跃次数能覆盖的右边界。
- `maxLength`：扫描过的位置再跳一次，最远可以覆盖到的下标，不是跳跃距离。

遍历时先更新 `maxLength = max(maxLength, i + nums[i])`。当 `i == end`，说明当前范围已经全部扫描完，需要增加一次跳跃，并将右边界扩展到 `maxLength`。
每一轮都考察了当前范围内所有可能的出发点，所以新的边界是增加一次跳跃后能到达的最远位置。按次数逐层扩展，首次覆盖终点时得到最少次数。

**口诀：遍历更新最远处，到达边界跳一步；边界换成最远处，终点无需再起步。**

## 示例与易错点

`[2, 3, 1, 1, 4]`：初始 `end=0`。扫描下标 `0` 后，最远为 `2`，计一次跳跃并令 `end=2`。扫描下标 `1、2` 后，最远为 `4`，计第二次跳跃并令 `end=4`，答案为 `2`。

- 必须先更新最远位置，再检查是否到达边界，才能计入边界位置自身的跳跃能力。
- 循环只到倒数第二个元素，到终点后不再起跳，避免多算一次。
- 单元素时循环不执行，返回 `0`。
- 此实现依赖题目保证末尾可达，不负责判断不可达输入。

## 复杂度

只扫描一次数组，时间复杂度 `O(n)`，辅助空间 `O(1)`。
