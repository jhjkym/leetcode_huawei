# 20. 有效的括号

- 算法分类：栈匹配。
- 数据结构：`stack<char>`。
- 对应代码：[020_valid_parentheses.cpp](./020_valid_parentheses.cpp)。
- 练习状态：`isValid` 已完成，12 组固定测例全部通过。

## 题意

给定只包含括号字符的字符串，判断括号是否有效。
有效字符串要求每个左括号都有同类型的右括号闭合，闭合顺序正确，并且右括号不能没有对应的左括号。
支持三种括号：`()`, `[]`, `{}`。

## 栈匹配思路

从左到右扫描字符串：

1. 遇到左括号时入栈，等待后面的对应右括号。
2. 遇到右括号时，栈必须非空，且栈顶必须是与它匹配的左括号；匹配后弹出栈顶。
3. 扫描结束后，只有栈为空才表示所有左括号都已经闭合。

栈顶代表当前最靠近的、尚未闭合的左括号，所以它必须优先与当前右括号匹配。
这正是括号嵌套的后进先出关系。

## 正确性要点

如果扫描中遇到没有左括号对应的右括号，或右括号类型与栈顶不一致，字符串立即无效。
如果扫描结束仍有左括号留在栈中，说明存在未闭合括号，也应返回 `false`。
只有每次关闭都匹配且最终栈为空时，字符串才有效。

## 边界与易错点

- 空字符串按题目定义通常是有效的，栈为空，返回 `true`。
- 不能只统计左右括号数量；`([)]` 数量相同但嵌套顺序错误。
- 右括号到来时必须先判断栈是否为空，再访问栈顶。
- 结束时要检查栈是否为空，不能只要扫描过程中没有失败就返回 `true`。
- 匹配关系应明确区分 `()`, `[]`, `{}`，不同类型不能互相抵消。
- 字符串只包含题目规定的括号；若扩展到其他字符，需要先定义处理规则。

## 复杂度

- 时间复杂度：`O(n)`，每个括号最多入栈和出栈一次。
- 辅助空间复杂度：`O(n)`，最坏情况下所有字符都是尚未闭合的左括号。
- 入口参数 `string s` 按值传递，会产生输入副本；若改为 `const string&` 可避免这次复制，算法栈空间仍按 `O(n)` 分析。

| 输入 | 预期 | 覆盖点 |
