# 66. 加一

- 算法分类：数组模拟、进位处理。
- 数据结构：数组 `vector<int>`。
- 对应代码：[066_plus_one.cpp](./066_plus_one.cpp)。

## 题意

数组 `digits` 按从高位到低位的顺序存储一个非负整数，每个元素都是一位数字。给这个整数加一，返回加一后的数字数组。

不能把整个数组直接转换成整数，因为数字可能很大。输入不含前导零（除数字 `0` 本身）。

## 示例

```text
输入：[1,2,3]
输出：[1,2,4]

输入：[4,3,2,1]
输出：[4,3,2,2]

输入：[9]
输出：[1,0]
```

## 固定测例覆盖

- 普通末位加一、个位为九、连续多个九。
- 全九导致数组长度增加。
- 中间出现零、进位在中间停止。
- 单元素、长数组和数值边界。

程序逐例输出预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

**口诀：从后往前加；不是九就加一返回；全是九则开头补一。**

从最低位开始处理：

1. 当前数字小于 `9`，直接加一并返回，进位已经结束。
2. 当前数字等于 `9`，改成 `0`，继续向前传播进位。
3. 如果所有数字都是 `9`，循环结束后在数组开头插入 `1`。

```cpp
for (int i = digits.size() - 1; i >= 0; --i) {
    if (digits[i] < 9) {
        ++digits[i];
        return digits;
    }
    digits[i] = 0;
}
digits.insert(digits.begin(), 1);
return digits;
```

例如 `[1, 2, 9, 9]`：末位 `9 → 0`，倒数第二位 `9 → 0`，再把 `2` 加一，得到 `[1, 3, 0, 0]`。`[9,9]` 全部清零后，在开头插入 `1`，得到 `[1,0,0]`。

## 易错点与复杂度

- 必须从最后一位向前处理，因为加一产生的进位向高位传播。
- 遇到非九数字后可以立即返回，不需要继续扫描。
- 全九时不要忘记扩展数组长度。
- `digits.insert(digits.begin(), 1)` 会在开头插入数字 `1`。
- 时间复杂度最坏为 `O(n)`，辅助空间为 `O(1)`（不计扩容产生的返回数组空间）。
