# 54. 螺旋矩阵

- 算法分类：矩阵边界模拟。
- 数据结构：二维数组、结果数组。
- 对应代码：[054_spiral_matrix.cpp](./054_spiral_matrix.cpp)。
- 练习状态：`spiralOrder` 核心实现待填写，固定测例已准备。

## 题意

给定一个 `m x n` 矩阵，按照顺时针螺旋顺序返回其中的所有元素。
访问顺序是：从左到右的上边界、从上到下的右边界、从右到左的下边界、从下到上的左边界，然后收缩边界继续处理内部区域。

## 边界模拟思路

用四个边界表示尚未访问的矩形：

- `top`：上边界行；
- `bottom`：下边界行；
- `left`：左边界列；
- `right`：右边界列。

每轮依次执行四条边：

1. 遍历 `left..right` 的上边界，完成后 `top++`。
2. 遍历 `top..bottom` 的右边界，完成后 `right--`。
3. 只有 `top <= bottom` 时，反向遍历下边界，完成后 `bottom--`。
4. 只有 `left <= right` 时，反向遍历左边界，完成后 `left++`。

最后两条边的条件很重要：矩阵收缩到单行或单列时，不能把同一批元素重复加入结果。

## 正确性要点

每轮处理当前未访问矩形的外圈，并在处理后收缩对应边界，因此已加入的元素不会再次被访问。
当上下或左右边界交错时，剩余区域为空；当只剩单行或单列时，条件判断保证它只被处理一次。
边界不断向内移动，最终覆盖矩阵中的每个位置，顺序保持顺时针。

## 边界与易错点

- 下边界和左边界是反向遍历，方向不要写反。
- 遍历下边界前检查 `top <= bottom`，遍历左边界前检查 `left <= right`。
- 收缩边界的时机要和对应一圈遍历匹配，不能提前或遗漏。
- 单行、单列、单元素矩阵都应正确处理。
- 不需要额外的访问矩阵，四个边界就能表示状态。
- 输出长度应等于 `m * n`，可作为完整性检查。
- 题目输入通常为非空矩形；若扩展到空矩阵，入口应先返回空结果。

## 复杂度

- 时间复杂度：`O(mn)`，每个矩阵元素恰好加入结果一次。
- 除返回结果外的辅助空间复杂度：`O(1)`，只使用四个边界和循环变量。
- 返回结果本身占 `O(mn)` 空间；入口通过引用接收矩阵，不复制输入。
