## 题意

将字符串按指定行数，从上向下、再斜向上反复排列，最后从第一行到最后一行依次读取。
输入字符串非空，`numRows >= 1`；字母、逗号和句点都作为普通字符参与排列。

例如 `s = "PAYPALISHIRING"`、`numRows = 3`：

```text
P   A   H   N
A P L S I I G
Y   I   R
```

三行分别为 `PAHN`、`APLSIIG`、`YIR`，拼接得到 `PAHNAPLSIIGYIR`。

## 按行收集的思路

用 `rows` 保存每一行已有的字符，并维护两个状态：

- `currentRow`：当前字符应写入哪一行，初始为 `0`。
- `direction`：下一步行号的变化量，向下为 `1`，向上为 `-1`。

先处理 `numRows == 1` 或 `numRows >= s.size()`，这两种情况直接返回原字符串。
其余情况创建 `numRows` 个空字符串，依次扫描输入字符：

1. 将字符追加到 `rows[currentRow]`。
2. 位于第一行时，将方向设为向下；位于最后一行时，将方向设为向上。
3. 按 `direction` 更新 `currentRow`，准备放置下一个字符。
4. 扫描完成后，从上到下依次拼接所有行，得到答案。

例如三行时，字符所在行号依次为 `0, 1, 2, 1, 0, 1, 2, 1, ...`。
记忆顺序：**放字符 → 边界转向 → 移到下一行 → 最后按行拼接**。

## 为什么不需要二维矩阵

题目只要求最后逐行读出的字符顺序，每个字符在其行内仍保持输入中的先后顺序。
因此只要判断字符属于哪一行并依次追加，就能得到正确结果。
示意图中的空格用于展示形状，不属于结果，不需要存储或补齐。

## 边界与易错点

- 只有一行时应提前返回，否则转向逻辑会让行号越界。
- 行数不少于字符数时，每个字符落在不同的行，最终顺序不变。
- 在更新行号之前判断边界并转向，避免走到 `-1` 或 `numRows`。
- 最后一行的下标是 `numRows - 1`，不要与行数混淆。
- 行内字符按到达顺序追加，最终按行号拼接，不能对字符排序。
- 逗号和句点原样保留，例如 `"A,B.C"`、两行的结果为 `"ABC,."`。

## 复杂度

设输入长度为 `n`。每个字符追加到对应行一次，最终再按行拼接一次，时间复杂度为 `O(n)`。
先处理行数不少于长度的情况，可避免为很大的 `numRows` 分配无用的空行。
分行字符串共保存 `n` 个字符，因此辅助空间为 `O(n)`；返回结果本身占 `O(n)` 空间。
入口参数 `string s` 按值传递，调用时还可能产生一份 `O(n)` 的输入副本。
