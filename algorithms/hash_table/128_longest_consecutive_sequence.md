# 128. 最长连续序列

- 算法分类：哈希表。
- 数据结构：哈希集合 `unordered_set<int>`。
- 对应代码：[128_longest_consecutive_sequence.cpp](./128_longest_consecutive_sequence.cpp)。
- 练习状态：已完成 `longestConsecutive` 核心实现，检查通过。
- 测试说明：16 组固定测例全部通过。

## 题意

给定一个未排序的整数数组 `nums`，找出数值连续的最长序列，返回它的长度。
序列元素不要求在原数组中相邻，重复数字不增加长度。要求算法时间复杂度为 `O(n)`。

## 示例

```text
输入：nums = [100, 4, 200, 1, 3, 2]
输出：4
解释：最长连续序列为 [1, 2, 3, 4]。

输入：nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]
输出：9
解释：最长连续序列为 [0, 1, 2, 3, 4, 5, 6, 7, 8]。

输入：nums = [1, 0, 1, 2]
输出：3
解释：最长连续序列为 [0, 1, 2]，重复的 1 不重复计数。
```

## 固定测例覆盖

- 典型乱序输入、空数组、单个元素。
- 全部重复、部分重复、没有相邻数值。
- 升序、降序、全负数、跨越零的序列。
- 多段长度不同或相同的连续序列。
- 接近正负十亿的数值、乱序完整连续序列。

运行代码会逐例输出预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

先将数组放入 `unordered_set<int>`，去除重复数字并支持快速查找。
遍历集合中的每个数字 `num`：如果 `num - 1` 存在，说明它不是连续序列的起点，直接跳过；否则从它开始，不断查找下一个数字并统计长度，最后更新最大长度。

例如 `[100, 4, 200, 1, 3, 2]`：只有从 `1` 开始时才会展开 `[1, 2, 3, 4]`；`2`、`3`、`4` 因为存在前驱，都会跳过。`100` 和 `200` 各自形成长度为 `1` 的序列，最终答案是 `4`。集合的遍历顺序不影响结果。

**记忆要点：集合先去重，有前驱就跳过；只从起点数，更新最长段。**

## 接口与易错点

- `unordered_set<int> set(nums.begin(), nums.end())`：用数组的迭代器范围构造哈希集合，自动去重。
- `set.count(x)`：在这个集合中，存在 `x` 时返回 `1`，否则返回 `0`。
- 遍历的是去重后的集合；如果遍历原数组，重复的起点可能导致同一段序列被反复扫描。
- `length` 从 `1` 开始，因为起点本身也算一个元素。
- 空数组不进入循环，返回初始值 `0`。
- 本题数值范围为正负十亿，`num - 1` 和 `cur + 1` 在 `int` 范围内。

## 复杂度

设数组长度为 `n`。构造集合平均需要 `O(n)` 时间。外层遍历每个不同的数字，内层只从序列起点出发，各段互不重叠，因此所有内层循环合计最多扫描 `O(n)` 个数字。

虽然有两层循环，平均总时间仍为 `O(n)`，不是 `O(n²)`。这里依赖哈希查找平均为 `O(1)`；哈希严重冲突时最坏时间可退化为 `O(n²)`。集合占用 `O(n)` 辅助空间。
