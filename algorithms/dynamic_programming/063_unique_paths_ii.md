# 63. 不同路径 II

- 算法分类：动态规划。
- 数据结构：二维网格、状态数组。
- 对应代码：[063_unique_paths_ii.cpp](./063_unique_paths_ii.cpp)。

## 题意

给定一个非空矩形网格 `obstacleGrid`，`0` 表示空地，`1` 表示障碍物。
机器人从左上角出发，每次只能向右或向下移动，不能进入障碍物格子，返回到达右下角的不同路径数量。

起点或终点存在障碍时，没有合法路径；只有一个无障碍格子时，答案为 `1`。

## 示例

```text
输入：[[0,0,0], [0,1,0], [0,0,0]]
输出：2
解释：绕过中间障碍，从上方或左侧沿边缘到达终点。

输入：[[0,1], [0,0]]
输出：1
解释：只能先向下，再向右。
```

## 固定测例覆盖

- 典型中间障碍、仅一条可行路径。
- 单格空地、单格障碍、起点或终点受阻。
- 单行、单列，及其途中存在障碍。
- 无障碍、整行障碍阻断。
- 首行或首列有障碍但仍可绕行。
- 非正方形网格。

程序逐例输出输入、预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

## 背诵模板

使用二维 `dp` 保存状态：`dp[i][j]` 表示从左上角到达第 `i` 行、第 `j` 列的路径数。

```cpp
int m = obstacleGrid.size();
int n = obstacleGrid[0].size();
vector<vector<int>> dp(m, vector<int>(n, 0));

for (int i = 0; i < m; ++i) {
    for (int j = 0; j < n; ++j) {
        if (obstacleGrid[i][j] == 1) continue;
        if (i == 0 && j == 0) {
            dp[i][j] = 1;
            continue;
        }
        if (i > 0) dp[i][j] += dp[i - 1][j];
        if (j > 0) dp[i][j] += dp[i][j - 1];
    }
}
return dp[m - 1][n - 1];
```

**口诀：起点置一；遇障碍置零；否则上方加左方。**

## 状态转移

如果当前位置是障碍物，不能到达：

```cpp
dp[j] = 0;
```

如果当前位置不是障碍物，它只能从上方或左方到达：

```text
dp[j] = 上方路径数 + 左方路径数
```

二维数组中，非障碍格子的状态转移为 `dp[i][j] = 上方 dp[i-1][j] + 左方 dp[i][j-1]`。

## 为什么 `dp[0][0] = 1`

把起点看作有一种“到达方式”，这样第一行、第一列可以自然传播。
如果起点是障碍物，第一格保持 `0`，后续所有位置都无法从起点到达。

例如第一行是 `[0, 0, 1, 0]`：

```text
dp[0]: [1, 1, 0, 0]
```

障碍物将当前位置及其右侧路径数截断为零。

## 易错点

- 障碍物保持 `0`，不能使用上方或左方路径，否则会错误地穿过障碍。
- 第 0 行没有上方，第 0 列没有左方，访问前要判断 `i > 0`、`j > 0`。
- 起点或终点是障碍物时自然得到 `0`。
- 输入是非空矩形网格，`obstacleGrid[0]` 可安全访问。

时间复杂度为 `O(mn)`，二维状态数组辅助空间为 `O(mn)`。

## 复杂度

设网格为 `m×n`，时间复杂度 `O(mn)`，辅助空间从二维 DP 的 `O(mn)` 压缩为一维 `O(n)`。
