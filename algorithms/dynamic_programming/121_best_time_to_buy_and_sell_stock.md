# 121. 买卖股票的最佳时机

- 算法分类：动态规划（一次遍历维护历史最低价）。
- 数据结构：价格数组、滚动变量（最低价与最大利润）。
- 对应代码：[121_best_time_to_buy_and_sell_stock.cpp](./121_best_time_to_buy_and_sell_stock.cpp)。
- 练习状态：`maxProfit` 已完成，12 组固定测例全部通过。

## 题意

`prices[i]` 是第 `i` 天的股票价格。只能选择某一天买入，并在之后的某一天卖出，最多完成一笔交易。
返回可以获得的最大利润；如果不存在任何盈利方案，返回 `0`。

约束：`1 <= prices.length <= 1e5`，`0 <= prices[i] <= 1e4`。数组非空，因此 `prices[0]` 可以直接取用。

## 思路

关键约束是卖出日必须严格晚于买入日。固定卖出日 `i` 时，最优买入价就是 `prices[0..i-1]` 中的最小值，
于是答案是所有 `i` 上 `prices[i] - min(prices[0..i-1])` 的最大值。

从左到右遍历一次，用两个滚动变量即可：

- `minPrice`：到当前位置之前出现过的最低价格；
- `best`：已知的最大利润。

对每个 `prices[i]`，先用 `prices[i] - minPrice` 更新 `best`，再用 `prices[i]` 更新 `minPrice`。
两步顺序保证买入日在卖出日之前；若把 `minPrice` 先更新，会允许同一天买卖，虽然差值为 `0` 不影响正确性，
但先算利润再更新更贴合状态定义。也可以把 `minPrice` 初始化为 `prices[0]`，从下标 `1` 开始遍历。

## 动态规划视角

令 `dp[i]` 表示以第 `i` 天为卖出日的最大利润，则 `dp[i] = max(dp[i - 1] + prices[i] - prices[i - 1], 0)`，
即经典最大子数组和作用在相邻差值序列上，答案为 `max(dp[i])`。这与维护历史最低价的写法等价，
滚动之后同样只需 `O(1)` 空间。

## 边界与易错点

- 价格单调递减时无法获利，必须返回 `0`，不要返回负数。
- 只有一个元素时返回 `0`。按官方约束数组非空，`minPrice = prices[0]` 是安全的；若入口可能收到空数组，必须先判空，否则 `prices[0]` 越界会段错误。
- 只能交易一次，不要把每一段上涨都累加，那是 122 题的解法。
- `minPrice` 若用哨兵初始化，选 `INT_MAX` 而不是 `0`，否则最低价永远更新不了。
- 不要写两层循环枚举买卖日对，`O(n^2)` 在大数据量下会超时。

## 复杂度

- 时间复杂度：`O(n)`，每个价格只访问一次。
- 空间复杂度：`O(1)`，只用两个滚动变量。
