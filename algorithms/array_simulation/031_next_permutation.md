# 31. 下一个排列

## 最优背诵代码

```cpp
class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = nums.size();
        int i = n - 2;

        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }

        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--;
            }
            swap(nums[i], nums[j]);
        }

        reverse(nums.begin() + i + 1, nums.end());
    }
};
```

## 思路

为了得到字典序中刚好更大的排列，需要让靠右的位置发生尽可能小的增长。

### 1. 从右向左找下降点

找到第一个满足 `nums[i] < nums[i + 1]` 的位置 `i`。

`i` 右边的后缀是非递增的。如果找不到，说明整个数组已经是最大排列，最后直接翻转成最小排列。

### 2. 从右向左找刚好更大的数

从末尾寻找第一个大于 `nums[i]` 的数字，与 `nums[i]` 交换。

因为后缀是非递增的，所以从右边找到的第一个更大数字，就是可以选择的最小较大值。

### 3. 翻转后缀

交换后，后缀仍是非递增的。将它翻转为递增顺序，就能让后缀尽可能小，得到下一个排列。

## 背诵口诀

> 从右找下降点；从右找刚大一点；交换以后，翻转后面。

## 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
