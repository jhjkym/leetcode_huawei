# 70. 爬楼梯

- 算法分类：动态规划。
- 数据结构：状态数组，或保存最近两项的滚动变量。
- 对应代码：[070_climbing_stairs.cpp](./070_climbing_stairs.cpp)。
- 练习状态：`climbStairs` 已完成；官方约束 `n >= 1` 的测例通过，额外的 `n = 0` 扩展约定仍需单独处理。

## 题意

楼梯共有 `n` 阶，每次可以爬 `1` 阶或 `2` 阶，求到达第 `n` 阶的不同方法数。
不同方法按每一步的阶数序列区分，例如 `1+2` 与 `2+1` 是两种方法。
这里固定测例额外包含 `n = 0`，按空序列有一种方法处理；题目常规约束从 `n = 1` 开始。

## 动态规划状态

令 `dp[i]` 表示到达第 `i` 阶的方法数。到达第 `i` 阶的最后一步只有两种可能：

- 从第 `i - 1` 阶迈 1 阶，贡献 `dp[i - 1]`；
- 从第 `i - 2` 阶迈 2 阶，贡献 `dp[i - 2]`。

因此状态转移为 `dp[i] = dp[i - 1] + dp[i - 2]`。
基础状态可以取 `dp[0] = 1`、`dp[1] = 1`，再从小到大计算；也可以特殊处理 `n = 1、2` 后从第三阶开始。

## 滚动变量

每次只依赖前两项，不必保留完整数组。用两个变量保存相邻状态，计算新值后向前滚动即可。
滚动变量与完整 `dp` 数组得到相同结果，但辅助空间从 `O(n)` 降为 `O(1)`。

## 边界与易错点

- `n = 1` 的答案是 `1`，`n = 2` 的答案是 `2`。
- 若按扩展状态处理 `n = 0`，应明确采用 `dp[0] = 1`，不能误返回 `0`。
- `1+2` 和 `2+1` 顺序不同，必须分别计数。
- 这是计数问题，不是求最少步数；不要使用 `min`。
- 不需要递归枚举所有路径，否则会产生指数级重复计算。
- 当前返回类型为 `int`，固定测例的最大值 `n = 45` 仍在 32 位有符号整数范围内；若扩大 `n`，应根据约束选择更宽类型。

## 复杂度

- 时间复杂度：`O(n)`，每个状态只计算一次。
- 使用完整状态数组时，辅助空间为 `O(n)`。
- 使用滚动变量时，算法辅助空间为 `O(1)`；入口和固定测例不需要复制额外的大数组。
