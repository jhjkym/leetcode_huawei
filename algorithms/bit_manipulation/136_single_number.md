# 136. 只出现一次的数字

- 算法分类：位运算。
- 数据结构：数组、整数变量。
- 对应代码：[136_single_number.cpp](./136_single_number.cpp)。
- 练习状态：已完成 `singleNumber` 异或实现，检查通过。
- 测试说明：16 组固定测例全部通过。

## 题意

给定一个非空整数数组 `nums`，其中只有一个元素出现一次，其余每个元素都恰好出现两次，返回只出现一次的元素。

要求时间复杂度为 `O(n)`，只使用 `O(1)` 额外空间。数组未必有序，重复元素不一定相邻，元素可以为正数、负数或零。

## 示例

```text
输入：nums = [2, 2, 1]
输出：1

输入：nums = [4, 1, 2, 1, 2]
输出：4

输入：nums = [1]
输出：1
```

## 固定测例覆盖

- 典型输入、单个正数、单个零、单个负数。
- 零出现一次或两次，全负数、正负数混合。
- 唯一元素位于开头、中间或结尾。
- 成对元素相邻或分散、数值边界。

所有输入均满足“一个元素出现一次，其余恰好两次”的约定。
程序逐例显示输入、预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

将 `ans` 初始化为 `0`，遍历数组，把每个元素异或到 `ans` 中。

```cpp
int ans = 0;
for (int num : nums) {
    ans ^= num;
}
return ans;
```

`^` 表示按位异或，二进制对应位相同得 `0`，不同得 `1`。`ans ^= num` 等价于 `ans = ans ^ num`。

核心性质：

- `a ^ a = 0`：相同的数抵消。
- `0 ^ a = a`：与零异或保持原值。
- 异或满足交换律、结合律，重复数字即使不相邻也能抵消。

例如 `[4,1,2,1,2]`：

```text
0 ^ 4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4
```

**口诀：初值设为零，遍历全异或；成对全抵消，留下单个数。**

## 易错点与复杂度

- `ans` 初始化为 `0`，不要用其他初始值影响结果。
- 异或按位运算，零和负数同样适用，不需要取绝对值。
- 不需要排序或创建哈希表。
- 本题保证其余元素恰好出现两次；若改为出现三次，这个模板不再适用。
- 遍历一次数组，时间复杂度 `O(n)`；只使用一个累加变量，辅助空间 `O(1)`，达到题目要求。
