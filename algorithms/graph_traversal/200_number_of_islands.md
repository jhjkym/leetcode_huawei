# 200. 岛屿数量

- 算法分类：图遍历（当前使用递归 DFS）、连通分量计数；也可使用 BFS。
- 数据结构：二维网格、递归栈；当前通过原地修改网格标记访问状态。
- 对应代码：[200_number_of_islands.cpp](./200_number_of_islands.cpp)。
- 练习状态：`numIslands` 已完成，12 组固定测例全部通过。

## 题意

给定由字符 `'1'`（陆地）和 `'0'`（水）组成的二维网格，返回岛屿的数量。
陆地只通过上、下、左、右四个方向连接，网格外可以看作水。
一座岛屿就是一个完整的陆地连通块，不要求形状规则，也不要求内部没有水。
对角线相邻不算连通，例如 `10 / 01` 中有两座岛屿。

## 把网格看成图

把每个陆地格子看作一个节点，把上下左右相邻的陆地之间看作有一条边。
从某个陆地出发，沿着这些边能够到达的所有陆地，属于同一座岛屿。
DFS 与 BFS 都可以完整遍历一个连通块，二者适用于本题。

整体处理步骤：

1. 用两层循环扫描整个网格，寻找尚未访问的陆地。
2. 每发现一块这样的陆地，岛屿数量加一，并从它出发遍历完整的连通块。
3. 遍历过程中标记所有到达的陆地，使外层扫描不会再次把它们计为新岛屿。

计数发生在发现新连通块时；遍历该块内部的其他陆地时不再增加计数。
例如全是陆地的矩形中虽然有很多格子，但第一次遍历会覆盖全部，答案为 `1`。

## 当前实现

`numIslands` 扫描网格，每遇到一个 `'1'` 就增加计数，并调用 `dfs` 遍历该岛屿。
`dfs` 先检查行列是否越界、当前位置是否为水，再将陆地改成 `'0'`，最后递归访问上下左右。
条件中的 `||` 按从左到右的顺序短路求值，越界时会直接返回，因此不会继续访问非法的 `grid[i][j]`。
标记发生在递归之前，同一块陆地不会被反复展开；处理结束后，输入网格中的陆地会全部变成 `'0'`。

## DFS / BFS 的选择

- DFS：沿某个方向尽可能深入，再返回探索其他分支，可用递归或显式栈实现。
- BFS：用队列保存已发现、尚待展开的位置，依次检查每个位置的四个邻居。
- 两者都只应继续访问“下标合法、是陆地、尚未访问”的格子。

DFS 用递归时，应先标记当前陆地，再向邻居递归，避免相邻格子反复调用。
BFS 应在发现陆地并将其入队时就标记，起点也需要这样处理。
如果等到出队才标记，同一个格子可能被多个邻居重复入队，增加额外工作。
使用显式栈时，也可以在入栈时标记，让每个陆地最多进入栈一次。

## 访问标记

可以选用以下任意一种方式：

- 原地标记：访问陆地后把对应字符从 `'1'` 改为 `'0'`，后续把它当成不可继续访问的位置。
- 独立标记：创建与网格同尺寸的 `visited`，访问后记录状态，保留原始网格。

原地标记不需要额外的访问数组，但 DFS 的栈或 BFS 的队列仍然占用空间；引用参数允许修改原网格，测试框架兼容这种写法。

## 边界与易错点

- 输入元素是字符，应比较 `'1'` 和 `'0'`，不是整数 `1` 和 `0`。
- 只检查上下左右四个方向，不能加入四个对角线方向。
- 先检查行、列下标是否越界，再读取 `grid[row][col]`。
- 计算向上、向左的坐标时会出现负数，使用有符号整数便于处理边界。
- 区分行数与列数，单行、单列及非正方形网格都应正确处理。
- 必须遍历完整个连通块；只标记起点或直接邻居会把同一岛屿重复计数。
- 全是水时返回 `0`，单个陆地时返回 `1`。
- 当前入口直接读取 `grid[0]`，要求网格至少有一行；若希望兼容空网格，可在入口加入 `if (grid.empty() || grid[0].empty()) return 0;`。
- 较大的连通块可能使递归很深，可改用显式栈或 BFS 队列，避免调用栈溢出。

## 复杂度

设网格有 `m` 行、`n` 列：

- 时间复杂度：`O(mn)`。扫描每个格子，每块陆地只被遍历一次，每次检查四个方向。
- 当前实现的辅助空间复杂度：最坏 `O(mn)`，用于 DFS 的递归调用栈；原地标记并不意味着辅助空间为 `O(1)`。
- 若使用独立 `visited`，另需 `O(mn)` 空间，总辅助空间仍为 `O(mn)`。
