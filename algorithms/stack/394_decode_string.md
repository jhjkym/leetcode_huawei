# 394. 字符串解码

- 算法分类：栈解析。
- 数据结构：重复次数栈、字符串栈。
- 对应代码：[394_decode_string.cpp](./394_decode_string.cpp)。
- 掌握状态：不会，标记为“背诵模板”。
- 验证状态：代码已完成，12 组固定测例全部通过。

## 题意

给定编码字符串，格式为 `k[encoded_string]`，将其中的内容重复 `k` 次并返回解码结果。
编码可以嵌套，例如 `3[a2[c]]` 解码为 `accaccacc`；数字可能有多位，普通字母可以直接保留。

## 栈解析思路

从左到右扫描字符，并维护当前正在构造的字符串 `current` 和当前数字 `number`：

1. 遇到数字时连续读取，组成完整的重复次数。
2. 遇到 `[` 时，把当前字符串和重复次数分别压入栈，然后清空 `current`、把数字归零，开始解析括号内部。
3. 遇到字母时，将其追加到 `current`。
4. 遇到 `]` 时弹出上一层字符串和次数，将当前内容重复指定次数后接回上一层字符串。

栈保存了每层括号开始前的上下文，因此嵌套括号按后进先出的顺序恢复。

## 背诵版模板

只记住四个动作：

1. 遇数字：`number = number * 10 + digit`。
2. 遇 `[`：数字入栈、当前字符串入栈，然后清空数字和当前字符串。
3. 遇字母：追加到当前字符串。
4. 遇 `]`：弹出次数和前缀，把当前字符串重复后接到前缀后面。

对应代码中的 `repeatStack`、`previousStack`、`current` 和 `number` 正好是一一对应的四个状态。
这道题标记为背诵模板，优先记住括号前保存状态、右括号恢复状态这一组固定动作。

## 正确性要点

每个 `[` 都保存了进入当前子串前的前缀和次数，每个 `]` 恰好恢复并合并这一层。
内部嵌套先完成解码，再作为整体重复，符合编码结构的递归定义。
扫描完成后，栈应为空，`current` 就是整个字符串的解码结果。

## 边界与易错点

- 多位数字必须连续累积，例如 `10[a]` 不能只读取第一位。
- 遇到 `[` 后要清空当前层数字和字符串，避免与内层混合。
- `]` 时重复的是完整的当前子串，不是最后一个字符。
- 嵌套层要先弹出上一层字符串，再将重复结果拼接回去。
- 没有括号的普通字符串应原样返回。
- 重复次数为 `1` 时仍要正常处理；不同层的字符串不能共用错误状态。
- 解码结果可能远大于输入，拼接时要注意题目约束和空间开销。

## 复杂度

- 解析扫描本身为 `O(n)`；若把输出字符复制成本计入，时间复杂度至少为 `O(L)`，其中 `L` 是解码结果长度。
- 两个栈的峰值空间与嵌套深度及中间字符串有关，计入结果和中间拼接后通常为 `O(L + n)`。
- 入口参数 `string s` 按值传递，会产生输入副本；可改为 `const string&` 避免这次复制。
