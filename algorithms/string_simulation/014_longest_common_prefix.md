# 14. 最长公共前缀

- 算法分类：字符串扫描。
- 数据结构：字符串数组 `vector<string>`。
- 对应代码：[014_longest_common_prefix.cpp](./014_longest_common_prefix.cpp)。
- 掌握状态：不会，标记为“背诵模板”，待复习背诵。
- 练习状态：已提供纵向扫描的核心实现。
- 测试说明：14 组固定测例全部通过。

## 题意

给定字符串数组 `strs`，返回所有字符串共有的最长前缀。如果不存在公共前缀，返回空字符串 `""`。
前缀必须从字符串的第一个字符开始，并且连续。

输入约定：`1 <= strs.size() <= 200`，每个字符串长度为 `0` 到 `200`，非空字符串仅含小写英文字母。

## 示例

```text
输入：strs = ["flower", "flow", "flight"]
输出："fl"

输入：strs = ["dog", "racecar", "car"]
输出：""
```

## 固定测例覆盖

- 典型公共前缀、完全没有公共前缀。
- 单个字符串、单个空字符串。
- 空字符串出现在数组开头或末尾。
- 所有字符串完全相同。
- 最短字符串在开头或末尾，且它本身就是公共前缀。
- 公共前缀仅有一个字符、单字符不匹配。
- 多个字符串在不同位置出现差异。
- 只有公共后缀，没有公共前缀。

`main` 会逐例打印输入、预期结果、实际结果与 PASS/FAIL，最后输出通过总数。

## 解题记录

以第一个字符串为基准，从左到右逐列检查其他字符串。
`i` 是字符下标，`j` 是字符串下标。只要某个字符串在第 `i` 列已经结束，或者字符不同，就返回 `strs[0].substr(0, i)`。
这里 `substr(0, i)` 表示从下标 `0` 开始取 `i` 个字符，不包含第 `i` 列。

例如 `["flower", "flow", "flight"]`：第 `0` 列都是 `f`，第 `1` 列都是 `l`，第 `2` 列分别是 `o`、`o`、`i`，因此返回前两个字符 `"fl"`。
此前所有列都匹配，而当前列无法匹配所有字符串，所以此时得到的前缀就是最长的。
如果第一个字符串全部检查完都没有差异，直接返回第一个字符串。

背诵口诀：**外层走字符，内层走各串；先判长度再比较，不同返回前面段；首串走完全返回。**

边界：题目保证数组非空；首串为空时循环不执行，返回空字符串；其他串为空时会在第 `0` 列返回空字符串；只有一个字符串时直接返回它自身。
`||` 从左到右短路求值，必须把长度检查放在字符访问前面。

设字符串数量为 `m`，最短字符串长度为 `L`，扫描时间为 `O(m(L + 1))`（包含空串或结束位置的检查）；除返回字符串外，辅助空间为 `O(1)`，返回结果占 `O(L)` 空间。
