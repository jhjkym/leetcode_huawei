# 283. 移动零

- 算法分类：数组、双指针。
- 对应代码：[283_move_zeroes.cpp](./283_move_zeroes.cpp)。
- 练习状态：已完成 `moveZeroes` 核心实现，测试通过。

## 题意

给定整数数组 `nums`，将其中所有 `0` 移动到数组末尾，同时保持所有非零元素的相对顺序。必须在原数组上操作，不能复制整个数组。

## 示例

```text
输入：nums = [0, 1, 0, 3, 12]
输出：[1, 3, 12, 0, 0]

输入：nums = [0]
输出：[0]
```

## 解题思路

使用两个指针：

- `read` 从左到右扫描数组。
- `write` 指向下一个非零元素应该放置的位置。

当 `nums[read]` 非零时，交换 `nums[write]` 和 `nums[read]`，然后让 `write` 向右移动。由于非零元素按照扫描顺序依次写入，它们的相对顺序不会改变；被交换到后面的零最终集中在数组末尾。

以 `[0, 1, 0, 3, 12]` 为例：扫描到 `1` 时将它换到下标 `0`，扫描到 `3` 时换到下标 `1`，扫描到 `12` 时换到下标 `2`，最终得到 `[1, 3, 12, 0, 0]`。

**记忆要点：读指针找非零，写指针守住非零区间的末尾。**

## 正确性说明

每次处理非零元素时，它都会被放到此前所有非零元素之后，因此已处理区间的前 `write` 个位置始终是按原顺序排列的全部非零元素。扫描结束后，所有非零元素都位于数组前部；其余位置只能是零，所以结果满足要求。

## 易错点

- 函数返回类型是 `void`，直接修改传入的 `nums`。
- 不能排序，否则会改变非零元素的相对顺序。
- `write == read` 时交换自身是安全的，代码也更简洁。
- 判断条件是 `nums[read] != 0`，负数同样属于非零元素。

## 复杂度

- 时间复杂度：`O(n)`，数组只扫描一次。
- 空间复杂度：`O(1)`，只使用两个指针和交换所需的常量空间。
