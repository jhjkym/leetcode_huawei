# 162. 寻找峰值

- 算法分类：二分查找。
- 数据结构：数组。
- 对应代码：[162_find_peak_element.cpp](./162_find_peak_element.cpp)。
- 练习状态：已完成二分查找实现，检查通过。
- 测试说明：已准备 16 组固定测例；模板通过编译检查，尚未验证算法实现。

## 题意

给定一个整数数组 `nums`，找到峰值元素并返回其下标。峰值元素严格大于它相邻的元素，边界外的元素视为负无穷。

数组中可能存在多个峰值，返回任意一个即可；模板测试使用峰值唯一的测例。要求时间复杂度为 `O(log n)`，数组长度至少为 `1`。

## 示例

```text
输入：nums = [1,2,3,1]
输出：2

输入：nums = [1,2,1,0,-1]
输出：1
```

## 固定测例覆盖

- 单元素、两端峰值、严格递增和严格递减。
- 中间峰值、多个局部峰值。
- 全负数、零值和数值边界。

测试会检查返回下标确实满足峰值定义，并对测例使用的峰值下标进行对比。

## 解题记录

比较 `nums[mid]` 和 `nums[mid+1]`：上坡时峰值在右侧，令 `left = mid + 1`；否则峰值在左侧（包括 `mid`），令 `right = mid`。最后 `left == right` 即为峰值下标。

**口诀：中点右边上坡，峰在右边；否则峰在左边；最后左右相等。**

每轮都缩小搜索区间，时间复杂度为 `O(log n)`，辅助空间为 `O(1)`。
