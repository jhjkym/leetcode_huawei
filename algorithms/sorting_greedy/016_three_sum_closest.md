# 16. 最接近的三数之和

- 算法分类：排序、双指针。
- 数据结构：数组。
- 对应代码：[016_three_sum_closest.cpp](./016_three_sum_closest.cpp)。
- 练习状态：已完成 `threeSumClosest` 核心实现，检查通过。
- 测试说明：16 组固定测例全部通过。

## 题意

给定整数数组 `nums` 和目标值 `target`，选择三个不同下标的元素，使它们的和与目标值的绝对差最小，返回这个和。

数组至少有三个元素。不同位置的元素可以具有相同数值，但不能重复使用同一个位置。题目保证最接近的和唯一；返回的是一个整数，不是三元组列表。

## 示例

```text
输入：nums = [-1, 2, 1, -4], target = 1
输出：2
解释：-1 + 2 + 1 = 2，与目标值的差为 1。

输入：nums = [0, 0, 0], target = 1
输出：0
```

## 固定测例覆盖

- 典型乱序数组、恰好三个元素。
- 全零、全部相等、重复元素。
- 恰好等于目标值、最接近的和小于或大于目标值。
- 目标值大于所有三数之和、目标值小于所有三数之和。
- 全负数、正负数混合、降序输入和数值边界。

测试时复制输入数组，允许实现原地排序。程序逐例显示输入、预期结果、实际结果和 PASS/FAIL，最后统计通过数量。

## 解题记录

先将数组升序排序，把前三个数的和作为初始答案 `best`。
枚举第一个数的下标 `i`，在它右侧设置 `left = i + 1`、`right = nums.size() - 1`，计算三数之和 `sum`。

- `sum == target`：差为零，直接返回。
- `abs(sum - target) < abs(best - target)`：当前和更接近目标，更新 `best`。
- `sum < target`：左指针右移，尝试增大总和。
- `sum > target`：右指针左移，尝试减小总和。

固定 `i` 后，如果当前和小于目标，那么保持 `left` 不变并缩小 `right` 只会让和更小，不可能更接近目标，因此可以排除当前 `left`。当前和大于目标时，同理可以排除当前 `right`。这说明双指针移动不会漏掉更优答案。

**记忆要点：排序定一个，两端找另外；先比距离差，小了左边加，大了右边减，相等直接返。**

## 易错点

- `best` 应初始化为真实存在的三数之和，不能随意设为 `0`。
- 使用绝对差比较接近程度，答案可以在目标值两侧。
- `i < left < right` 保证三个下标不同。
- 相等时直接返回是正确的提前结束条件。
- 不做去重也能正确求出最接近的和，不影响 `O(n²)` 时间复杂度。
- 本题保证至少三个元素，当前 `nums.size()-2` 有效；可提前将长度转成 `int`，统一下标类型，避免有符号与无符号比较。
- 当前实现会修改数组顺序。题目数值范围内，三数之和以及与目标的差可安全使用 `int`。

## 复杂度

排序需要 `O(n log n)` 时间，外层枚举 `O(n)` 次，每次双指针合计移动 `O(n)` 次，总时间为 `O(n²)`。
双指针本身使用 `O(1)` 辅助空间；计入当前 GCC 标准库排序的调用栈，辅助空间为 `O(log n)`。
